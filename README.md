# [Stock Analyst v2.0] 한국 주식 테마 주도주 & 종목 퀀트 분석 시스템

PRD v2.0 명세와 **참고자료(web-crawler)**의 고신뢰성 크롤러 아키텍처를 결합하여 구현한 한국 주식 테마 주도 대장주 발굴, 사용자 지정 특정 종목 퀀트 분석, 증권사 HTS급 4단 인터랙티브 차트 시각화 및 멀티 타임프레임 기술적 분석 보고서 자동화 시스템입니다.

---

## 1. 주요 특징 및 아키텍처

### 1) 참고자료(Web Crawler) 패턴 완벽 반영
* **`RateLimiter` & Polite Crawling**: 초당 요청 제한(`0.4s` 딜레이)과 연속 에러 시 지수 백오프(`Exponential Backoff`)를 적용하여 네이버 증권 서버 부하 및 IP 차단 방지 (`src/crawler/utils.py`)
* **가짜 200/WAF 챌린지 감지 (`detect_softblock`)**: 단순 HTTP 상태코드뿐 아니라 WAF 챌린지 및 빈 껍데기 응답을 사전 감지
* **개인정보 감지 (`detect_pii`)**: 수집된 데이터셋 내 개인정보 노출 여부 사전 검증
* **데이터 무결성 검증 (`validate_values`)**: 결측치 비율 및 컬럼 데이터 타입 검증
* **진행 상태 추적 (`ProgressTracker`)**: 파이프라인 단계별 진행 상황을 `output/.../progress.json`에 기록
* **스타일링된 멀티시트 엑셀 출력 (`export_excel`)**: 자동 열 너비, 네이비 볼드 헤더, 오토필터, 천 단위 콤마가 적용된 전문 엑셀 파일 생성

### 2) 듀얼 분석 모드 지원 (테마 주도주 발굴 & 특정 종목 타겟 분석)
* **모드 1: 실시간 상위 테마 대장주 발굴**:
  - 네이버 증권 실시간 테마 API를 통해 당일 상승률/거래량 상위 **Top 8 테마**를 실시간 제시 (`src/crawler/theme_service.py`)
  - 테마 선택 시 구성 종목의 3일 누적 거래대금, 3일 상승률, 120일 신고가 근접도를 가중 합산한 **Leader Score** 공식으로 1등 대장주 및 2등 부대장주 자동 판정
    $$\text{Leader Score} = (0.45 \times \text{거래대금 점수}) + (0.35 \times 3\text{일 누적 상승률}) + (0.20 \times \text{신고가 근접도})$$
* **모드 2: 특정 종목 타겟 정밀 분석**:
  - 사용자가 입력한 종목명(예: `삼성전자`, `SK하이닉스`) 또는 6자리 종목코드(`005930`)를 즉시 자동 인식
  - 동일한 멀티 타임프레임 기술적 지표, 펀더멘털 실적 및 세분화 수급 분석 파이프라인 일괄 수행

### 3) 펀더멘털 및 1차·2차 세분화 수급 정밀 진단
* **밸류에이션 & 분기 실적 연동**:
  - 네이버 증권 모바일 API 및 기업 재무 API를 연계하여 시가총액, PER/PBR, EPS/BPS, 배당수익률 및 **최근 분기 매출액/영업이익/영업이익률**을 실시간 연동 (N/A 원천 방지)
  - 증권사 컨센서스 목표주가 및 최신 리서치 리포트 요약 제공
* **핵심 투자 포인트 4대 요인 체계**:
  - 🟢 **핵심 호재 4대 요인** (거래대금 쏠림, 메이저 스마트머니 유입, 실적 모멘텀, 이평선 정배열)
  - 🔴 **핵심 악재 4대 요인** (이격도 과열, 직전 고점 매물벽 저항, 수급 손바뀜, 테마 순환매 분산)
  - 🎯 **핵심 모니터링 변수 4대 트리거** (20일 이격도 115% 돌파, 5일선 지지 붕괴, 장초반 30분 거래량 분출 속도, 외인·기관 순매도 전환)
* **투자 주체별 수급 2단계 분해 분석**:
  - **1차 수급**: 개인, 외국인, 기관의 3거래일 일별 순매수량 및 3일 누적 합계, 외인 지분율 추이
  - **2차 기관 세분화**: 기관 수급을 **금융투자(차익/패시브), 연기금 등(중장기 가치/안전판), 투신(액티브 모멘텀), 보험/은행(보수적 안정)**으로 분해하여 자금 성격 정밀 진단

### 4) 증권사 HTS급 4단 인터랙티브 차트 엔진 (`src/pipeline/chart_engine.py`)
* Plotly 기반 4개 수직 패널 X축 완전 동기화 (Shared X-axis):
  - **패널 1 (메인 시세 & 매물대)**: 일봉 캔들스틱(상승 빨강/하락 파랑), 이동평균선 4종(MA 5/20/60/120), 볼린저밴드(20, 2) 음영 오버레이, **매물대 분석(Volume Profile)** 수평 누적 거래량 바 및 **최대 매물대(★POC선)** 강조
  - **패널 2 (거래량)**: 일별 거래량 바(전일비 상승 빨강/하락 파랑) 및 20일 거래량 이동평균선(VMA20)
  - **패널 3 (RSI)**: RSI(14) 곡선 및 과열(70) / 침체(30) 수평 기준선
  - **패널 4 (MACD)**: MACD(12, 26) + Signal(9) + 0선 오실레이터 히스토그램
* **HTS 편의 기능**: 주말/공휴일 비거래일 공백 자동 제거(`rangebreaks`), 마우스 휠 줌/팬 동기화, 크로스헤어 통합 툴팁

### 5) 구글 드라이브 연도별 서브폴더 자동 아카이빙 (`src/pipeline/drive_storage.py`)
* 분석 완료 즉시 로컬 출력뿐 아니라 구글 드라이브 내 연도별/실행회차별 폴더로 자동 동기화 보존:
  - **저장 경로**: `G:\내 드라이브\120.주식종목분석\{YYYY}\{YYYYMMDD_HHMM_종목명}\`
  - **산출물 3종**: 마크다운 보고서(`.md`), 반응형 웹 보고서(`.html`), 스타일링 엑셀 데이터(`.xlsx`)
  - 실행 시점 분(Minute) 단위 기록으로 동시간대/동일 종목 다중 실행 시에도 덮어쓰기 없이 안전하게 독립 보관

## 2. 디렉토리 구조

```
Stock_Analyst/
├── .agents/
│   └── skills/
│       ├── Technical Analysis.md     # 기술적 분석 표준 SOP (멀티타임프레임, 볼밴+ADR, 매물대, HTS 차트)
│       └── Qualitative Analysis.md   # 펀더멘털/수급 SOP (실적, 4대 호재/악재, 1·2차 수급, 드라이브 아카이빙)
├── src/
│   ├── crawler/
│   │   ├── utils.py                  # RateLimiter, detect_softblock, detect_pii, validate_values
│   │   ├── progress.py               # ProgressTracker
│   │   ├── export_excel.py           # openpyxl 기반 멀티시트 엑셀 내보내기
│   │   ├── naver_crawler.py          # 테마, 종목, 일별시세, 멀티타임프레임 차트 크롤러
│   │   └── theme_service.py          # 실시간 거래량/상승률 Top 8 상위 테마 조회 서비스
│   ├── screener/
│   │   └── screener.py               # 3일 누적통계, Leader Score 랭킹 및 필터링
│   └── pipeline/
│       ├── indicators.py             # 멀티 타임프레임 MA/볼린저밴드/RSI/MACD/매물대 계산
│       ├── mcp_bridge.py             # 밸류에이션(시총/PER/PBR), 분기 실적, 공시, 1·2차 수급 브릿지
│       ├── chart_engine.py           # Plotly 기반 HTS 4단 인터랙티브 동기화 차트 생성 엔진
│       ├── drive_storage.py          # 구글 드라이브 연도별 서브폴더({연도}/{년월일시_종목명}) 저장소
│       ├── sop_analyst.py            # 9개 섹션 규격 SOP 리포트 생성 및 6대 Verification Matrix 검증
│       └── gdocs_exporter.py         # Markdown, Styled HTML, Google Docs 내보내기
├── output/                           # 로컬 실행 회차별 결과 폴더 (run_YYYYMMDD_HHMMSS)
├── app.py                            # Streamlit 대화형 웹 대시보드 UI
├── run_ui.bat                        # 윈도우 원클릭 웹 UI 실행 배치 파일
├── main.py                           # CLI 통합 파이프라인 및 스케줄러 실행 스크립트
├── requirements.txt                  # 프로젝트 의존성 라이브러리 목록
├── prd.md                            # PRD v2.0 요구사항 정의서
└── README.md                         # 본 프로젝트 안내 문서
```

## 3. 실행 방법

### 1) 환경 확인 및 의존성 설치
```bash
pip install -r requirements.txt
```

### 2) 실행 모드별 사용법

#### 🖥️ [추천] 대화형 웹 대시보드 UI 실행 (Streamlit)
```bash
# 원클릭 배치 파일 실행 (Windows)
run_ui.bat

# 또는 수동 실행
streamlit run app.py
```
* **UI 주요 기능**:
  - **[모드 1: 테마주 대장주 분석]**: 실시간 거래량/상승률 상위 테마 Top 8 중 원하는 테마 선택 후 즉시 1등 대장주 발굴
  - **[모드 2: 특정 종목 분석]**: 종목명(예: 삼성전자) 또는 6자리 종목코드 입력 후 심층 퀀트 분석 수행
  - **[증권사 HTS급 4단 인터랙티브 차트]**: 캔들스틱 + MA(5/20/60/120) + 볼린저밴드 + 매물대(POC) + 거래량(VMA20) + RSI(14) + MACD 동기화 차트 열람 (최근 60/90/120봉 기간 선택 지원)
  - **[화면 실시간 열람]**: 상단 핵심 KPI 요약 카드, 9개 섹션 마크다운 보고서, 펀더멘털 & 1차/2차 세분화 수급 요약표, 엑셀/HTML 다운로드
  - **[구글 드라이브 자동 아카이빙]**: 분석 완료 시 구글 드라이브 영구 저장소에 자동 보존

#### 💻 [CLI 모드 1] 시장 전체 테마 스크리닝 및 1위 대장주 자동 발굴
```bash
# 기본 실행 (상위 5개 테마, 테마당 상위 10개 종목 스크리닝 후 1위 대장주 리포트 생성)
python main.py

# 옵션 지정 실행
python main.py --themes 10 --stocks-per-theme 15 --output output
```

#### 💻 [CLI 모드 2] 사용자 지정 특정 종목 타겟 정밀 분석
```bash
# 종목명으로 지정 분석 (예: SK하이닉스, 삼성전자, 에코프로비엠)
python main.py --stock "SK하이닉스"

# 6자리 종목코드로 즉시 분석
python main.py --stock 005930
```

#### 💻 [CLI 모드 3] 평일 장 마감 자동 실행 모드 (Phase 5 스케줄링)
```bash
# 매일 평일 15:40에 자동으로 주도주 스크리닝 및 보고서 생성 실행
python main.py --schedule 15:40
```

### 2) 구글 드라이브 연도별 서브폴더 영구 보관소
* **디렉토리 구조**: `G:\내 드라이브\120.주식종목분석\{YYYY}\{YYYYMMDD_HHMM_종목명}\`
